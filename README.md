# CTF Writeup Collection

My personal collection of Capture The Flag (CTF) write-ups documenting my cybersecurity learning journey through platforms like Hack The Box (HTB), TryHackMe (THM), and personal labs.

Each writeup walks through the investigation process, including reconnaissance, hypotheses, techniques, failed attempts, exploitation, and lessons learned. The goal is to understand **why a solution works**, not just how to obtain the flag.

## Objectives

- Document hands-on cybersecurity practice.
- Explain the reasoning behind each step.
- Preserve mistakes and dead ends as learning opportunities.
- Build a reusable knowledge base of security techniques and concepts.

## Disclaimer

All activities are conducted in authorized CTF environments and personal labs. Write-ups are intended for educational purposes. Active challenge solutions are shared only when permitted by the relevant platform or event rules.
